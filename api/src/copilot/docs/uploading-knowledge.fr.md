# Téléverser des connaissances

Votre bot fonde ses réponses sur les documents que vous téléversez sous *Bot IA & Contenu → Connaissances*.

**Formats acceptés :** PDF, DOCX, TXT, Markdown, texte brut.

**Limites de taille :** 20 Mo par fichier sur Essential, 50 Mo sur Pro, 200 Mo sur Enterprise. Les images et fichiers audio ont leurs propres limites.

**Ce qu'il vaut mieux téléverser :**
- Fiches produits, tarifs, FAQ, descriptions de services
- Règles internes que le bot doit respecter (« nous remboursons sous 30 jours », « nos techniciens se déplacent dans un rayon de 25 km »)
- Tout ce qu'un client peut demander et qui ne figure pas sur votre site

**Ce qu'il vaut mieux NE PAS téléverser :**
- Données confidentielles de collaborateurs ou de clients — le bot peut les citer telles quelles
- Anciennes versions ou brouillons contradictoires — le bot les mélange et répond de façon confuse

Après le téléversement, le traitement prend 30 à 60 secondes. Le document apparaît dans la liste avec un indicateur d'état ; dès qu'il affiche « Prêt », le bot s'en sert.
