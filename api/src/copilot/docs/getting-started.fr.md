# Démarrer

Axentrio donne à votre entreprise un bot IA qui discute avec les visiteurs de votre site et recueille des leads, ainsi qu'un portail pour le configurer et le suivre.

Les trois premières choses à faire après votre inscription :

1. **Configurez votre bot.** Ouvrez *Bot IA & Contenu* dans le menu latéral. Choisissez le ton de votre marque, rédigez vos instructions et téléversez les documents de connaissances (PDF, FAQ, conditions) sur lesquels le bot doit s'appuyer.
2. **Installez le widget.** Ouvrez *Bot IA & Contenu → Embed*, copiez l'extrait de code et collez-le juste avant `</body>` sur votre site.
3. **Recueillez votre premier lead.** Dès qu'un visiteur donne son e-mail ou son téléphone, il apparaît dans *Leads*.

Tout le reste — réservations via agenda, réseaux sociaux, apparence personnalisée — se trouve dans le menu latéral une fois ces trois étapes faites.
