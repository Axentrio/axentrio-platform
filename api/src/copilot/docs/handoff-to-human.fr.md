# Transfert vers un collaborateur

Parfois le bot ne s'en sort pas — la question est trop précise, le visiteur est mécontent, ou il demande explicitement à parler à quelqu'un. Le bot transfère alors la conversation à l'un de vos collègues.

**Quand cela se déclenche :**
- Le visiteur demande un humain (« parler à quelqu'un », « puis-je avoir un responsable »)
- Le bot estime qu'il ne peut pas répondre avec assez de certitude
- Vos instructions lui demandent de transmettre certains sujets (remboursements, plaintes, etc.)

**Ce que voit le collaborateur :** la conversation apparaît dans *Boîte de réception* avec une étiquette de transfert et les derniers messages du visiteur. Le collaborateur ouvre la conversation, écrit sa réponse, et le visiteur la voit apparaître en direct. Le bot reste en retrait jusqu'à ce que le collaborateur lui rende la main.

**Ajouter des collaborateurs :** *Équipe → Inviter un collègue*. Chaque personne invitée reçoit son propre accès. Tout le monde dans l'équipe peut reprendre une conversation transférée.

**Notifications :** les collaborateurs reçoivent une notification sur leur écran dès qu'un transfert arrive. En option, un e-mail pour les conversations qui attendent plus de cinq minutes.

Le transfert est inclus dans toutes les formules.
