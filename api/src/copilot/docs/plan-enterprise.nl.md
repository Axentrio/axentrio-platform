# Enterprise-abonnement

Enterprise is bedoeld voor bedrijven met veel berichten, meerdere medewerkers of bijzondere eisen rond naleving.

**Alles uit Pro, plus:**
- De hoogste daglimiet aan berichten (in de praktijk onbeperkt voor een gewone kmo)
- Grotere uploadlimieten voor kennisdocumenten
- Meerdere bots per klant (bijvoorbeeld een aparte bot voor klanten en voor intern gebruik)
- Meerdere kennisbanken
- Voorrang bij telefonische ondersteuning
- Eigen contractvoorwaarden (SLA, vast aanspreekpunt)

**Prijs:** op maat — neem contact op via sales@axentrio.com of plan een gesprek via de pagina Help.

**Overstappen vanuit Pro:** Enterprise regel je niet zelf in het portaal. Neem contact op en het team stelt de overstap in met de voorwaarden die bij je volume en teamgrootte passen.
