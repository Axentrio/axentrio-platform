# Indice de réussite et lacunes

L'*Indice de réussite* dans le menu latéral affiche les **lacunes** : les sujets sur lesquels vos clients posent des questions et où votre bot n'a pas su les aider.

**Qu'est-ce qu'une lacune ?** Lorsque le même sujet revient chez au moins trois visiteurs différents sur les sept derniers jours et que les réponses du bot ne les satisfont pas, ce sujet apparaît comme une lacune.

**Pourquoi s'y intéresser ?** Chaque lacune est l'occasion soit :
- de téléverser un document de connaissances qui y répond (c'est la solution la plus fréquente),
- soit d'ajuster les instructions personnalisées de votre bot.

Après une correction, l'analyse de la nuit suivante vérifie si la lacune est comblée. Si oui, elle disparaît d'elle-même de la liste.

**Gravité :**
- **Rouge** — fréquent et récent (priorité haute)
- **Orange** — modéré
- **Vert** — comblé (satisfait récemment ; reste visible un moment pour que vous voyiez le résultat de votre travail)

**Comment les lacunes sont détectées :** chaque nuit, un évaluateur IA lit les conversations, détermine si la question du visiteur a trouvé réponse et regroupe les tendances. Plus de détails dans *Aide & FAQ*.

**Formule :** l'Indice de réussite est inclus dans toutes les formules payantes.
