# Connecter Cal.com

L'intégration Cal.com permet à votre bot de réserver des rendez-vous directement dans votre agenda — sans copier de lien ni envoyer d'e-mail de suivi.

**Formule :** nécessite Pro ou Enterprise. Sur Essential, *Réservations* affiche un cadenas Pro dans le menu latéral.

**Configuration :**
1. Ouvrez *Réservations → Intégrations* dans le menu latéral.
2. Cliquez sur **Connecter Cal.com**. Vous êtes redirigé vers Cal.com pour autoriser Axentrio.
3. Choisissez ensuite le type d'événement que le bot peut proposer (par exemple « consultation de 30 minutes »).
4. Le bot propose dès lors des créneaux et crée les rendez-vous pendant les conversations.

**Comment le bot s'en sert :** quand un visiteur demande vos disponibilités ou souhaite un rendez-vous, le bot interroge Cal.com en direct et crée la réservation dès que le visiteur confirme.

**Déconnecter :** *Réservations → Intégrations → Déconnecter*. Les rendez-vous existants restent dans Cal.com ; le bot cesse simplement de proposer de nouveaux créneaux.
