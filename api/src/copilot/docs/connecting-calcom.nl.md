# Cal.com koppelen

Met de Cal.com-koppeling boekt je bot afspraken rechtstreeks in je agenda — geen links kopiëren, geen mails achteraf.

**Abonnement:** vereist Pro of Enterprise. Op Essential toont *Boekingen* in de zijbalk een Pro-slot.

**Instellen:**
1. Open *Boekingen → Integraties* in de zijbalk.
2. Klik op **Cal.com koppelen**. Je gaat naar Cal.com om Axentrio toestemming te geven.
3. Kies daarna welk afspraaktype de bot mag aanbieden (bijvoorbeeld "consultatie van 30 minuten").
4. De bot stelt vanaf nu vrije momenten voor en boekt afspraken tijdens gesprekken.

**Hoe de bot het gebruikt:** vraagt een bezoeker naar beschikbaarheid of wil hij een afspraak, dan haalt de bot je vrije momenten live op bij Cal.com en maakt hij de boeking zodra de bezoeker bevestigt.

**Ontkoppelen:** *Boekingen → Integraties → Ontkoppelen*. Bestaande afspraken blijven in Cal.com staan; de bot stopt gewoon met nieuwe momenten aanbieden.
