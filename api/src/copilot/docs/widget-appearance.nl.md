# Uitzicht van de widget

De chatwidget kan in je eigen huisstijl gezet worden op Pro en Enterprise.

**Abonnement:** een eigen uitzicht is een functie vanaf Pro. Op Essential gebruikt de widget de standaardstijl van Axentrio plus een klein "Powered by Axentrio"-label.

**Wat je kunt aanpassen (vanaf Pro):**
- **Hoofdkleur** — achtergrond van de bel, verzendknop, accenten
- **Positie** — rechtsonder (standaard) of linksonder
- **Welkomstbericht** — de tekst die verschijnt als de widget voor het eerst opengaat
- **Avatar van de bot** — upload een vierkante afbeelding (png/jpg, max. 500 kB)
- **Vermelding verbergen** — haal het "Powered by Axentrio"-label volledig weg

**Waar je dit instelt:** *AI-bot & inhoud → Weergave*.

**Live voorbeeld:** de pagina toont een live voorbeeld van de widget — je ziet kleurwijzigingen meteen, nog voor je opslaat.

**Mobiel en desktop:** de widget past zich automatisch aan het scherm aan. Op mobiel gaat hij schermvullend open. Kleur en avatar gelden voor allebei.

**Terugzetten:** klik onderaan de pagina op **Standaardwaarden herstellen**. De widget krijgt meteen weer de standaardstijl van Axentrio.
