# Connecter votre agenda de réservation

Les réservations passent par le planificateur intégré d'Axentrio. Connectez un agenda : le bot propose vos vrais créneaux libres pendant les conversations, inscrit chaque rendez-vous confirmé dans cet agenda et ne réserve jamais par-dessus un événement déjà présent.

**Formule :** nécessite Pro ou Enterprise. Sur Essential, *Réservations* affiche un cadenas Pro dans le menu latéral.

**Choisissez un agenda — Google ou Outlook :**
1. Ouvrez *Réservations* dans le menu latéral et lancez la *Configuration* (ou *Paramètres → Planificateur*).
2. Cliquez sur **Connecter Google Agenda** ou **Connecter Outlook**. Vous êtes redirigé vers Google ou Microsoft pour autoriser Axentrio.
3. Après validation, l'agenda s'affiche comme *Connecté* avec l'adresse du compte. Le bot y lit vos disponibilités et y inscrit les rendez-vous.

Un bot utilise un seul agenda à la fois — Google ou Outlook, pas les deux.

**Si le message « Reconnexion nécessaire » apparaît :** le lien a expiré ou l'accès a été révoqué ; le bot ne peut plus lire vos disponibilités et se contente alors d'enregistrer des demandes. Cliquez sur **Reconnecter** pour rétablir la réservation — c'est une ré-autorisation, pas une nouvelle configuration.

**Déconnecter :** ouvrez les paramètres du planificateur et déconnectez. Les rendez-vous existants restent dans votre agenda ; le bot cesse simplement de proposer de nouveaux créneaux.

> Axentrio n'utilise pas Cal.com. Les réservations se synchronisent avec votre propre agenda Google ou Outlook via le planificateur intégré.
