# Essential-abonnement

Essential is het instapabonnement — alles wat je nodig hebt om een bot op je website te zetten en leads te verzamelen.

**Wat inbegrepen is:**
- Eén bot, één kennisbank
- Websitewidget (de chatbel op je site)
- Leads vastleggen (bezoekers geven e-mailadres of telefoonnummer, jij krijgt een lead)
- Overzicht van je leads en export naar Excel
- Een daglimiet aan berichten die past bij kleine tot middelgrote drukte
- Ondersteuning via e-mail

**Wat er NIET in zit (daarvoor heb je Pro nodig):**
- Boekingen via Cal.com
- Het label "Powered by Axentrio" verbergen
- Een eigen uitzicht voor de widget (kleuren, huisstijl)
- Eigen leadvelden en doorstuurregels
- De AI-platformassistent (deze Copilot)

Je kunt op elk moment overstappen naar Pro via *Instellingen → Facturatie* — de wijziging gaat meteen in en je betaalt alleen voor de rest van de maand.
