# Consulter les leads

Dès que le bot recueille les coordonnées d'un visiteur, celles-ci apparaissent dans *Leads*.

**Ce que contient un lead :** nom, e-mail, téléphone (s'il a été donné), source (quel canal), la conversation d'origine et le moment où il a été recueilli.

**Filtrer :** filtrez par source (widget, Facebook, WhatsApp, etc.) ou par période. La recherche se fait par nom ou par e-mail.

**Exporter :** cliquez sur **Exporter** pour télécharger tous les leads affichés — pratique pour les importer dans votre CRM.

**Ouvrir un lead :** cliquez dessus pour lire la conversation complète dont il provient. Utile comme contexte avant de rappeler la personne.

**Toujours aucun lead ?** Si votre widget est installé, que des gens discutent mais que la liste reste vide, vérifiez que *Leads* est activé sous *Paramètres → Fonctionnalités* (vous pouvez le désactiver si vous ne voulez pas que le bot demande des coordonnées). Attention aussi : un lead n'est enregistré que si le visiteur donne lui-même un e-mail ou un téléphone — le bot ne les déduit pas d'une simple salutation.
