# Votre période d'essai

Les nouveaux clients reçoivent automatiquement un **essai Pro** gratuit — toutes les fonctionnalités Pro sont ouvertes et aucune carte n'est demandée au départ.

**Durée :** 14 jours à partir de l'inscription.

**Ce qui fonctionne pendant l'essai :**
- Toutes les fonctionnalités Pro sont actives : réservations Cal.com, identité visuelle, champs de lead personnalisés et l'assistant IA de la plateforme
- Le plafond quotidien de messages est celui de Pro
- Votre liste complète de leads

**Fin de l'essai :**
- Trois jours avant, vous recevez un rappel par e-mail.
- Le dernier jour, nous vous invitons à ajouter un moyen de paiement pour continuer avec Pro.
- Sans paiement, votre compte **bascule automatiquement sur Essential** (et non sur la formule gratuite) — le bot continue de fonctionner, mais les fonctionnalités réservées à Pro s'arrêtent.

**Ajouter un paiement pendant l'essai :** *Paramètres → Facturation → Ajouter un moyen de paiement*. Votre carte n'est débitée qu'à la fin de l'essai, au prorata jusqu'à la prochaine date de facturation.

**Résilier pendant l'essai :** *Paramètres → Facturation → Résilier*. Vous conservez Pro jusqu'au terme normal de l'essai, puis basculez sur la formule gratuite.
